# Shift Planner

Jednoduchý základ aplikácie na plánovanie pracovných zmien zamestnancov.

## Cieľ

Postupne vytvoríme aplikáciu, ktorá bude vedieť:
- evidovať zamestnancov,
- definovať typy zmien,
- vytvárať pracovný kalendár,
- prideľovať zmeny,
- kontrolovať konflikty,
- neskôr automaticky generovať rozpis.

## Aktuálny stav

Toto je čistý základ projektu. Docker zatiaľ nie je potrebný.

## Spustenie

1. Vytvor virtuálne prostredie:
   `python -m venv .venv`

2. Aktivuj ho vo Windows PowerShell:
   `.venv\Scripts\Activate.ps1`

3. Spusti aplikáciu:
   `python main.py`
